# Reels Sav Bot

Личный Telegram-бот для скачивания видео из Instagram Reels, TikTok и X/Twitter.
Видео отправляется файлом, который можно переслать. Посты X отображаются с текстом,
фотографиями и цитатами; несколько фотографий приходят альбомом.

Бот работает в личных сообщениях с пользователями из списка разрешённых Telegram ID.
Пустой список закрывает доступ всем. Команда `/id` доступна любому пользователю
в личке и показывает только его собственный ID.

## Запуск

Нужны Python 3.11+ и [uv](https://docs.astral.sh/uv/getting-started/installation/).
Поддерживаются macOS и Linux. Для видео с отдельной звуковой дорожкой нужен
[FFmpeg](https://ffmpeg.org/download.html).

1. Создай бота через [@BotFather](https://t.me/BotFather), команда `/newbot`.
2. В папке проекта создай настройки и установи зависимости:

   ```sh
   cp .env.example .env
   chmod 600 .env
   uv sync --locked
   ```

3. Заполни `TELEGRAM_BOT_TOKEN` в `.env` и запусти:

   ```sh
   uv run --locked python -m reels_bot
   ```

4. Отправь боту `/id`, запиши полученный номер в `ALLOWED_USER_IDS` и перезапусти процесс.
   Чтобы добавить других людей, укажи их ID через запятую.

Бот отвечает, пока процесс запущен. Для постоянной работы нужна постоянно работающая
машина с интернетом. Домен и открытые входящие порты не нужны: используется long polling.
Запускай только одну копию с одним токеном. Остановка — `Ctrl+C`.

## Настройки

| Переменная | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен из BotFather |
| `ALLOWED_USER_IDS` | Разрешённые числовые ID через запятую |
| `COOKIES_FILE` | Необязательный путь к cookies в формате Netscape |
| `DOWNLOAD_TIMEOUT` | Таймаут загрузки: 10–600 секунд, по умолчанию 180 |
| `MAX_FILE_MB` | Максимальный размер файла: 1–49 МБ, по умолчанию 49 |

Настройки читаются из `.env` в текущей папке или переменных окружения.
Переменные окружения имеют приоритет. После изменения настроек перезапусти бота.
Токен и cookies храни локально: `.env` и распространённые имена файлов cookies
исключены из Git. Если используешь другое имя для файла cookies, добавь его в `.gitignore`.

## Использование

- `/start`, `/help` — подсказка; `/id` — собственный Telegram ID.
- Отправь ссылку или перешли сообщение с ней. Поддерживаются ссылки в подписях и скрытые ссылки.
- До 5 ссылок в сообщении и до 4 видео из публикации; одновременно обрабатываются 2 пользователя.
- У постов X текст прикрепляется к фото или альбому. Длинный текст отправляется отдельно целиком.
- Каждый видеофайл удаляется после подтверждения отправки Telegram. Временные данные
  удаляются также при ошибке или отмене. После аварийного завершения остатки убираются
  при следующем запуске или запросе; активные загрузки защищены файловыми блокировками.

## Загрузчик и ограничения

Используется [yt-dlp](https://github.com/yt-dlp/yt-dlp) с `curl-cffi` для запросов TikTok
в режиме браузера. Предпочтение отдаётся MP4 со звуком, H.264 и высоте до 720p.
Ролики без звука также поддерживаются. Для склейки отдельных дорожек или смены
контейнера нужен FFmpeg. Автоматического сжатия нет; слишком большие файлы отклоняются.

Текст и фотографии X получаются через сторонний [FxEmbed API](https://docs.fxembed.com/).
Сервис получает ID запрошенного поста и IP машины бота. При его сбое бот отдельно
пробует загрузить видео через yt-dlp.

Доступность зависит от ограничений платформ, региона, IP и авторизации. При необходимости
можно указать локальный файл cookies; автоматического чтения браузера нет.
Проект предназначен для личного исследовательского использования.

Обновление загрузчика:

```sh
uv lock --upgrade-package yt-dlp
uv sync --locked
```

## Проверки

Проверить настройки без сети и вывода токена:

```sh
uv run --locked python -m reels_bot --check
```

Тесты и проверка кода:

```sh
uv run --locked pytest -q
uv run --locked ruff check .
uv run --locked ruff format --check .
```

Тесты проверяют доступ по ID, ссылки, ответы API, отправку медиа, ограничения размера
и времени, удаление файлов и восстановление после аварийного завершения.
Доступность платформ и доставку в Telegram проверяй отдельно со своим ботом.
